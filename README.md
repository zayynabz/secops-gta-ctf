# 🎮 Ask CJ — SecOps CTF Challenge

> **An interactive Capture The Flag web application combining cybersecurity challenges with the world of GTA: San Andreas.**

**Ask CJ** is a browser-based CTF experience developed for the **SecOps Club**, combining cybersecurity learning with an immersive GTA: San Andreas-inspired interface.

Players progress through **10 questions** covering GTA lore and cybersecurity concepts. Achieving a score of **6/10 or higher** unlocks the final flag.

## 🎯 The Challenge

**Ask CJ** combines two themes:

* 🎮 **GTA: San Andreas**
* 🔐 **Cybersecurity**

Players answer a series of questions covering both GTA lore and fundamental cybersecurity concepts.

The challenge is designed to combine **technical learning, gaming culture, and interactive web design** into a single CTF experience.

### 🏁 Objective

* Answer **10 questions**
* Test your knowledge of GTA and cybersecurity
* Reach a score of **6/10 or higher**
* 🔓 Unlock the final flag

The challenge is available in:

* 🇬🇧 **English**
* 🇫🇷 **French**



## ✨ Features

### 🎮 Immersive Visual Experience

The interface combines GTA-inspired visuals with a cyberpunk and synthwave aesthetic.

Features include:

* 🌧️ Animated Matrix-style rain
* 🕸️ Dynamic cybersecurity node network
* 🛣️ Animated 3D perspective grid
* 🌆 Synthwave-inspired environment
* 💡 Neon visual effects
* 🎞️ Animated interface elements

### 🖥️ GTA-Style HUD

A custom HUD inspired by GTA's interface displays:

* ❤️ **Respect**
* ⭐ **Wanted Level**
* 💵 **Cash**

These elements provide visual feedback throughout the challenge and reinforce the game's atmosphere.

### 🕹️ Interactive Cheat Console

The experience includes a GTA-style cheat console featuring iconic codes:

```text
HESOYAM
AEZAKMI
BAGUVIX
```

The console is integrated directly into the interface as part of the interactive experience.

### 🔊 Procedural Retro Audio

Retro-inspired sound effects are generated directly in the browser using the **Web Audio API**.

The audio system provides interaction feedback while contributing to the overall game-inspired atmosphere.

### 🌍 Bilingual Support

The challenge supports:

**🇬🇧 English · 🇫🇷 Français**

Players can switch between languages during the experience.

### 📱 Responsive Design

The interface is designed to adapt to:

* 📱 Mobile devices
* 📲 Tablets
* 💻 Desktop screens

The layout and controls adjust to different screen sizes for a consistent experience across devices.
